# Library Management System

## Project Description

Library Management System is a desktop application developed using Python and Tkinter.

The application helps manage library books and members. Users can add, edit, delete, search, sort, borrow and return books through a graphical user interface.

## Features

- Add books
- Edit books
- Delete books
- View all books
- Add members
- Edit members
- Delete members
- View all members
- Search books by ID, title, author and category
- Sort books by title, author, year and category
- Borrow books
- Return books
- Check book availability
- View library statistics
- Save data using JSON files
- Error handling with messagebox
- Unit testing with unittest

## Technologies Used

- Python
- Tkinter
- JSON
- unittest
- Git
- GitHub
